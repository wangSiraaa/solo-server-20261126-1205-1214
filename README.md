# 插画工作台后端（本地、无外部依赖）

一套面向“左手手柄 + 模拟工作台”的插画作业后端。画师在录制台把手柄手势录成**可移植动作谱**，
交接给同事后，同事在模拟工作台上领单、按签名按法实际打键，系统把每一笔“谁把哪格改成了什么”
记进台账。仅用 Python 标准库，`python3 app.py` 即可启动。

## 启动与验收

```bash
python3 app.py          # 默认 http://127.0.0.1:8806，数据落在 ./data
python3 demo.py         # 端到端验收：随机端口起服务，51 项断言，含杀进程重启
```

环境变量：`BENCH_PORT`（端口）、`BENCH_DATA`（数据目录，JSON 原子落盘）。

## 选定的运营模式：可移植动作谱（题面第一种工作室）

- **录制台**只接收原始按放事件（`press`/`release`/`tick`/`connect`/`disconnect`），
  按录制手柄的默认布局把事件流解析成一串**操作意图**（选格、取色、填色、切面板）。
  动作谱存的是意图，不存任何脚本，系统也没有任何执行用户代码的入口。
- **交接签名**：把意图谱拿到目标手柄的指定布局上逐条做安全分析——该布局必须存在能完成
  意图的绑定，且同一个（面板, 按键组合, 长短）组合不能同时绑到别的动作。全部通过才签为
  安全按法（signed plan）；任一意图找不到无冲突按法则整张谱拒绝签名，作业保持未签名、
  不能开工。交接人可以换布局重签。
- **模拟工作台**：客户从 `/controllers/{id}/jobs` 领到指派给本手柄的作业，开工拿到签名谱
  的按键指引（guide），随后只能通过事件接口实际打 `press`/`release`。引擎按该手柄的真实
  按放与面板转移解释，授权范围外或已封稿的填色被拒，成功的落笔进台账。

## 关键语义（题目要求明确给出的裁量权，这里定下规则）

| 议题 | 规则 |
| --- | --- |
| 短键何时落定 | 所有键放开后进入 250ms 静默窗；窗内无新按键则落定。新 `press` 到来时上一笔立即落定、另起一笔；仍有键按住时的新按键并入当前手势 |
| 短按 vs 长按 | 按住时长 ≥180ms 为 `hold`，否则 `tap`。短按可以是长按手势的开头，靠时长 + 静默窗消歧 |
| 同键异义 | 绑定三元组是（面板, 组合, 长短）。`SIDE` 短按在画布=选下一格，在色板=换颜色；`SIDE` 长按=给当前格填当前色；按住 `LAYER` 再按 `SIDE`=选上一格；`B` 切面板 |
| 中途换面板 | 手势按“起手势那一刻”的面板解释；面板切换动作本身属于下一笔。录制与执行共用同一套面板/选区/取色状态转移 |
| 设备掉线 | 已落定并写入台账的落笔**永久保留**；掉线时仍按住或静默窗未走完的在飞手势**整笔丢弃**，面板与选区复位到作业起始状态；`connect` 后可在同一张作业上继续 |
| 封稿 | 画格被画师封稿后，任何作业对它的填色都被拒且不产生台账；只有原封稿画师能撤回 |
| 合法新作业 | 建单必须声明非空且真实存在的 `allowed_cells`、合法画师与已有录制，否则 400/404 |

## 内置操作与默认布局 L1

`CELL_NEXT` 选下一格、`CELL_PREV` 选上一格、`COLOR_NEXT` 色板换色、`FILL` 填当前色、
`OPEN_PALETTE`/`OPEN_CANVAS` 切面板。手柄 `C1` 另带一个故意有冲突的布局 `L2`
（`SIDE` 短按同时绑 `CELL_NEXT` 和 `FILL`，且缺长按填色绑法），用于演示签名被拒。

## HTTP 接口摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/works` `/works/{id}` | 作品与画格（颜色、封稿画师） |
| GET | `/controllers` `/controllers/{id}/jobs` | 手柄布局；客户领取指派给本手柄的作业 |
| POST | `/recordings` | 提交事件带，服务端解析为意图动作谱 |
| GET | `/recordings/{id}` | 动作谱与逐笔解析日志 |
| POST | `/jobs` | 建合法作业（录制、授权画格、画师、起始格） |
| POST | `/jobs/{no}/sign` | 按布局做安全分析并签名；不安全返回 409 且无副作用 |
| POST | `/jobs/{no}/execution` | 领单开工，返回 exec_id 与按键指引 |
| POST | `/execution/{id}/events` | 送入一批手柄事件，返回逐笔效果 |
| POST | `/execution/{id}/end` | 结束执行，冲掉静默窗最后一笔，作业 completed |
| GET | `/execution/{id}` | 执行运行态（面板、选区、当前色、结果；不跨重启） |
| POST | `/works/{id}/cells/{cell}/seal` | 封稿/撤回（`sealed:false` 仅原封稿画师可用） |
| GET | `/jobs/{no}` `/jobs/{no}/ledger` | 作业详情；按作业号查落笔台账 |
| GET | `/works/{id}/-/ledger` | 作品级全量台账 |

事件对象示例：

```json
{"type": "press", "button": "SIDE", "ts": 100}
{"type": "release", "button": "SIDE", "ts": 160}
{"type": "tick", "ts": 410}
{"type": "disconnect", "ts": 780}
{"type": "connect", "ts": 900}
```

合法按键：`SIDE`、`B`、`LAYER`。时间戳必须在同一会话内单调不减；未连接时的 `press`、
没有对应 `press` 的 `release` 都会被 400 拒绝。

## 验收脚本覆盖的场景（对应题面）

1. 同键异义与短/长前缀消歧；
2. 基准：移到第二格 → 填蓝，两种互不冲突输入，作业只获准改第二格；
3. 变体：选格手势改成回第一格，两格均有权时落笔地点跟到第一格；
4. 第二格执行前被正式封稿 → 填色被拒、无新台账、无蓝被覆盖；
5. 换 L2 布局签名因误触冲突/缺按法被拒，未签名不能开工，换回 L1 签名通过；
6. 掉线保留已落定填色、丢弃在飞手势、复位后重连续做；
7. 非法建单被拒、同事可独立办合法新作业；
8. 补色作业读到既有颜色并改红，随后**杀掉服务进程重启**，按作业号与作品号查询台账，
   画格颜色与全部落笔记录跨重启保留。
